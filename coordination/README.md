# The coordinating session's folder

Length: 13 lines. Last section: "What is here".

Kept by the coordinating session that sets up and runs the Process4 trial for Bob. Moved here from branch `claude/process4-design-handoff-7w8nh8` of neobobkrause/process3 on 20 Nov 2026, on Bob's word, so that the work on Process4 lives in Process4's repository. This folder is not part of the design: it changes no file in `design/`, `build/` or `starting_texts/`, and holds no rule. PROCESS's own folder is `process/`.

## What is here

- `handoffs/`: each coordinating session's handoff to the next; the newest rules over the earlier ones and passes on facts, not rules.
- `trial/`: the set-up log of the trial, every act and finding with times, and the stage 0 report.
- `building_sessions/`: the prompts that started the tool's building sessions.
- `owner_page/desk.html`: the source of Bob's standing page, https://claude.ai/artifact/3eWSU2EvP27ttdJBZGjDJT.
- The older design drafts, the owner's words and the evidence stay in neobobkrause/process3 (`process4/` on the branch above), read by a plain clone. The design in force is `design/` and `build/` here.
